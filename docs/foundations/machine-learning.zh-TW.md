# 機器學習

## 直覺

傳統程式：人寫規則，電腦依規則把輸入變輸出。
機器學習：人給「輸入＋輸出範例」，電腦自己找出規則（模型參數）。

形式化：給定資料 \( D = \{(x_i, y_i)\} \)，從假設空間 \( \mathcal{H} \) 中找函數 \( f_\theta \)，使期望損失最小：

\[
\theta^* = \arg\min_\theta \; \mathbb{E}_{(x,y)\sim P}\big[L(f_\theta(x), y)\big] \approx \arg\min_\theta \frac{1}{n}\sum_i L(f_\theta(x_i), y_i) + \lambda R(\theta)
\]

## 任務類型

| 類型 | 說明 | 例子 | 常用演算法 |
|---|---|---|---|
| 分類 | 預測類別 | 垃圾郵件、腫瘤良惡性 | 邏輯迴歸、決策樹、SVM、神經網路 |
| 迴歸 | 預測連續值 | 房價、藥物劑量 | 線性迴歸、梯度提升樹 |
| 分群 | 找出相似群組 | 客戶分群、細胞類型 | k-means、DBSCAN、階層式分群 |
| 降維 | 壓縮特徵 | 視覺化、去噪 | PCA、t-SNE、UMAP |
| 異常偵測 | 找出不尋常樣本 | 詐欺、設備故障 | Isolation Forest、自編碼器 |
| 排序與推薦 | 排出偏好順序 | 搜尋、電商推薦 | 矩陣分解、雙塔模型 |
| 序列預測 | 預測未來 | 股價、需求預測 | ARIMA、RNN、Transformer |

## 經典演算法一覽

- **線性迴歸／邏輯迴歸**：可解釋、快速，許多領域的基準線。
- **k 近鄰（kNN）**：記住所有資料，看鄰居投票。
- **決策樹**：一連串 if-else；易解釋但易過擬合。
- **隨機森林**：多棵樹的 bagging。
- **梯度提升樹（XGBoost、LightGBM、CatBoost）**：表格資料的王者，Kaggle 常勝軍。
- **支援向量機（SVM）**：最大化邊界，核技巧處理非線性。
- **單純貝氏**：假設特徵條件獨立，文字分類的快速基準。
- **PCA**：找變異最大的方向。
- **高斯混合模型（GMM）與 EM 演算法**：軟分群。

!!! tip "表格資料先試樹模型"
    在中小型表格資料上，梯度提升樹經常勝過深度學習（Grinsztajn et al., 2022）。但近年表格基礎模型（如 TabPFN）在小資料上表現亮眼，值得一試。

## 泛化：機器學習的核心問題

### 過擬合與欠擬合

- **欠擬合**：模型太簡單，訓練誤差就很高。
- **過擬合**：模型記住訓練資料的雜訊，訓練誤差低但測試誤差高。

### 偏差—變異權衡

\[
\text{期望誤差} = \text{偏差}^2 + \text{變異} + \text{不可約雜訊}
\]

傳統觀點：模型越複雜，偏差降、變異升，存在最佳複雜度。
現代觀點：**雙下降（double descent）**——超大模型在超過「剛好能擬合訓練資料」的門檻後，測試誤差會再次下降，這解釋了為何參數遠多於資料的深度網路仍能泛化（Belkin et al., 2019；Nakkiran et al., 2019）。

### 正規化方法

L1（稀疏）、L2（權重衰減）、早停、資料增強、Dropout、整體學習。

## 實驗方法

1. **資料切分**：訓練／驗證／測試。測試集只在最後用一次。
2. **交叉驗證**：k-fold，資料少時必備。
3. **時間序列要依時間切分**，避免用未來預測過去。
4. **避免資料洩漏**：前處理（標準化、特徵選擇）只能在訓練集上 fit。
5. **評估指標要符合任務**：

| 指標 | 何時用 |
|---|---|
| 準確率 | 類別平衡時 |
| 精確率／召回率／F1 | 類別不平衡（醫療篩檢重召回、垃圾信重精確） |
| ROC-AUC、PR-AUC | 需要看不同門檻的整體表現；極度不平衡用 PR-AUC |
| MAE、RMSE、R² | 迴歸 |
| 校準度（ECE） | 需要可信的機率輸出（醫療、金融） |

## 學習理論簡介

- **PAC 學習**：在多少樣本下，能以高機率學到近似正確的假設。
- **VC 維度**：假設空間的容量度量。
- **沒有免費午餐定理**：沒有任何演算法在所有問題上都最好，歸納偏誤（inductive bias）是必要的。
- **歸納偏誤**：CNN 的平移不變性、RNN 的時間結構、GNN 的置換不變性，都是把領域知識放進模型。大腦的演化結構也可視為一種強大的歸納偏誤（見 [NeuroAI](../brain-mind/neuroai.md)）。

## 與認知科學的連結

- **概念學習**：人類常從少量例子學會新概念（少樣本學習），貝氏程式學習（Lake et al., 2015）試圖模擬這點。
- **原型理論 vs 範例理論**：心理學的類別學習理論，分別對應「類別中心」與 kNN 式的記憶比對。
- **統計學習**：嬰兒能從音節轉移機率切分詞彙（Saffran et al., 1996），與語言模型的學習方式有相似之處。
