# 法律

本頁討論 AI **用於**法律實務的情形。關於規範 AI 的法律，請見[法律、政策與治理](../../society/governance/index.md)。

## 概況

| 領域 | 例子 |
|---|---|
| 法律研究 | 由 LLM 驅動、搜尋判例與法規的工具（Westlaw 與 Lexis 的 AI 功能、Harvey、CoCounsel） |
| 合約審閱與起草 | 條款擷取、風險標示、修訂標記、依範本進行的協商 |
| 電子證據開示（e-discovery） | 自 *Da Silva Moore*（2012）起，法院接受的技術輔助審閱（預測編碼） |
| 盡職調查 | 併購案中審閱數千份文件 |
| 司法近用 | 自助工具、表格填寫、白話的法律說明 |
| 法院 | 案件管理、逐字稿、翻譯；部分司法管轄區已發布法官使用 AI 的指引 |
| 法律預測 | 預測案件結果（準確性與倫理仍有爭議） |
| 法遵 | 追蹤法規變動、對應政策 |

## 幻覺問題

- *Mata v. Avianca*（紐約南區法院，2023）：律師因提交了由 ChatGPT 生成的虛構判例之書狀而遭到制裁。此後，全球已記錄了數百起類似事件
- 在史丹佛的一項評估中，即使是專門的法律 RAG 工具，在相當比例的查詢中仍會產生幻覺（Magesh et al., 2024）
- 專業規範：美國律師協會第 512 號正式意見書（2024）要求，使用生成式 AI 時須具備能力、保守秘密、進行查證，並收取合理費用

## 評測基準

- GPT-4 通過了美國統一律師考試（Katz et al., 2023），不過其百分位數的說法後來被下修（Martínez, 2024）
- LegalBench：超過 160 項法律推理任務
- 律師考試對法律實務只是微弱的代理指標

## 高風險法律決策的風險

- **刑事司法中的風險評估**：COMPAS 爭議（ProPublica, 2016）指出其錯誤率存在種族差異，並引出了公平性定義之間不可能同時滿足的結果（見[倫理與公平](../../society/ethics/index.md)）
- **正當程序**：當事人有要求說明與提出異議的權利
- 上傳客戶文件時的**保密與特權**問題
- 面向消費者的法律 AI 所引發的**未經授權執業**問題
