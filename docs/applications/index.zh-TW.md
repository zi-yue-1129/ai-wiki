## 跨領域的模式

| 模式 | 出現的地方 |
|---|---|
| **大規模的感知**（視覺、語音、感測器） | 醫療影像、製造檢測、農業、自動駕駛 |
| **從結構化資料做預測** | 金融、設備維護、能源、物流 |
| **生成式設計** | 蛋白質、分子、材料、晶片、媒體 |
| **以語言作為專業知識的介面** | 法律、醫療、教育、客服、軟體 |
| **模擬與替代模型** | 天氣、物理、工程、機器人 |
| **自主代理人** | 軟體工程、科學研究、營運 |

## 常見的失敗模式

1. **分布偏移**：在某家醫院、某個國家或某個季節驗證過的模型，到了其他地方就失效。
2. **捷徑學習**：模型依賴虛假線索（掃描儀型號、浮水印、郵遞區號）。
3. **自動化偏誤**：人類過度信任輸出結果。
4. **評估指標用錯**：只看準確率而不看校準度，只做回顧性分析而不做前瞻性試驗。
5. **工作流程不符**：技術上很好的工具，不符合人們實際的工作方式。
6. **責任空窗**：AI 輔助的決策出錯時，責任歸屬不清楚。
