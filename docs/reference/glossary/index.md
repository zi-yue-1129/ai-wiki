# Glossary

English terms with Traditional Chinese (Taiwan) equivalents. Terms link to the page where they are explained.

## A–C

| Term | 中文 | Short definition |
|---|---|---|
| Activation function | 啟動函數 | Nonlinearity applied to a neuron's weighted sum ([Deep Learning](../../theory/deep-learning/index.md)) |
| Active learning | 主動學習 | Model chooses which examples to label ([Active Learning](../../theory/paradigms/active/index.md)) |
| Adversarial example | 對抗樣本 | Input perturbed to fool a model |
| Agent | 代理人／智慧體 | System that perceives and acts toward goals ([AI Agents](../../theory/models/agents/index.md)) |
| Alignment | 對齊 | Making AI pursue intended goals ([Safety & Alignment](../../society/safety-alignment/index.md)) |
| Attention | 注意力機制 | Weighted mixing of information by relevance ([Transformers](../../theory/models/transformer/index.md)) |
| Autoencoder | 自編碼器 | Network that compresses and reconstructs input |
| Backpropagation | 反向傳播 | Computing gradients with the chain rule |
| Bandit | 多臂吃角子老虎問題 | One-step decision problem balancing exploration and exploitation ([Online Learning](../../theory/paradigms/online/index.md)) |
| Batch normalisation | 批次正規化 | Normalising activations across a mini-batch |
| Bayesian inference | 貝氏推論 | Updating beliefs with Bayes' rule ([Probabilistic Methods](../../theory/paradigms/probabilistic/index.md)) |
| Benchmark | 基準測試 | Standard task for comparing models ([Evaluation](../../engineering/evaluation/index.md)) |
| Bias–variance trade-off | 偏差—變異權衡 | Tension between underfitting and overfitting |
| Brain-computer interface (BCI) | 腦機介面 | Decoding brain signals to control devices ([BCI](../../brain-mind/bci/index.md)) |
| Catastrophic forgetting | 災難性遺忘 | Losing old skills when learning new ones ([Continual Learning](../../theory/paradigms/continual/index.md)) |
| Chain-of-thought | 思維鏈 | Step-by-step reasoning in text |
| Cognitive architecture | 認知架構 | Integrated theory of the mind's structure ([Cognitive Architectures](../../brain-mind/cognitive-architectures/index.md)) |
| Complementary learning systems | 互補學習系統 | Fast hippocampal + slow cortical learning ([Memory & Learning](../../brain-mind/memory-learning/index.md)) |
| Connectome | 連結體 | Complete wiring diagram of a nervous system |
| Context window | 上下文視窗 | Tokens a model can attend to at once |
| Contrastive learning | 對比學習 | Learning by pulling similar pairs together and pushing others apart |
| Convolutional neural network (CNN) | 卷積神經網路 | Network with local, shared filters ([Computer Vision](../../theory/models/computer-vision/index.md)) |
| Cross-entropy | 交叉熵 | Standard classification loss |

## D–H

| Term | 中文 | Short definition |
|---|---|---|
| Data augmentation | 資料增強 | Creating modified copies of training data |
| Differential privacy | 差分隱私 | A formal guarantee that one person's data barely changes the output ([Privacy and Data Protection](../../society/privacy/index.md)) |
| Diffusion model | 擴散模型 | Generative model that learns to denoise ([Generative Models](../../theory/generative/index.md)) |
| Distillation | 知識蒸餾 | Training a small model to imitate a large one |
| Distribution shift | 分布偏移 | Test data differ from training data |
| Dopamine | 多巴胺 | Neuromodulator signalling reward-prediction error |
| DPO | 直接偏好最佳化 | Aligning a model directly on preference pairs |
| Dropout | 丟棄法 | Randomly zeroing units during training |
| Embedding | 嵌入（向量） | Dense vector representation |
| Emergent ability | 湧現能力 | Capability appearing at larger scale |
| Encoder / decoder | 編碼器／解碼器 | Parts of a network that compress and generate |
| Epoch | 訓練週期 | One pass over the training data |
| Explainable AI (XAI) | 可解釋 AI | Methods for explaining predictions ([Interpretability](../../society/interpretability/index.md)) |
| Federated learning | 聯邦學習 | Training without centralising data ([Federated Learning](../../theory/paradigms/federated/index.md)) |
| Few-shot learning | 少樣本學習 | Learning from very few examples |
| Fine-tuning | 微調 | Further training a pre-trained model ([Training](../../engineering/training/index.md)) |
| Foundation model | 基礎模型 | Large pre-trained model adapted to many tasks |
| Free-energy principle | 自由能原理 | Theory that brains minimise prediction error/surprise ([Cognitive Science](../../brain-mind/cognitive-science/index.md)) |
| GAN | 生成對抗網路 | Generator vs discriminator |
| Generalisation | 泛化 | Performing well on unseen data |
| Gradient descent | 梯度下降 | Iteratively stepping against the gradient |
| Graph neural network (GNN) | 圖神經網路 | Network operating on graphs ([GNNs](../../theory/models/gnn/index.md)) |
| Grid cell / place cell | 網格細胞／位置細胞 | Neurons encoding spatial position |
| Hallucination | 幻覺 | Confident but false model output |
| Hebbian learning | 赫布學習 | "Fire together, wire together" |
| Hippocampus | 海馬迴 | Brain region for episodic memory and navigation |
| Hyperparameter | 超參數 | Setting chosen before training (learning rate, etc.) |

| Pre-training | 預訓練 | Large-scale initial self-supervised training |
| Prompt | 提示 | Input instructions to a model ([Prompt Engineering](../../engineering/prompting/index.md)) |
| Prompt injection | 提示注入 | Malicious instructions hidden in model inputs |
