# Frequently Asked Questions

Answers to questions about this wiki and about where to begin with AI. Each answer links to the page that covers it in more detail.

## About the wiki

**What is this wiki?**
An open, comprehensive wiki of artificial intelligence. It covers the theory and models behind AI, the links to brain and cognitive science, applications in many fields, engineering practice, and the social questions AI raises. See the [home page](../../index.md) for the sections.

**Who is it for?**
Anyone who wants an organised map of the field: students, researchers, practitioners and curious readers. Each page starts with an overview that assumes little background, and links to the prerequisites.

**Is it written in English or Chinese?**
English is the main language. Many pages also have a Traditional Chinese (Taiwan) translation, marked by a `.zh-TW` file. A page without a translation shows the English version.

**How reliable is the content?**
Each page states its status (stub, draft or complete) and the date it was last reviewed. Claims should be backed by a References section that lists the papers, official documents or other sources they rely on. A weekly maintenance report checks page structure, status and external links.

**Can I reuse the material?**
Content is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), and code snippets are under the MIT licence. You may share and adapt the material, including commercially, if you credit the source and release your changes under the same licence.

**What is still missing?**
The [Roadmap](../roadmap/index.md) lists planned topics and the pages that do not yet exist.

## Using the wiki

**Where should I start?**
If you want a guided route, follow the [Learning Paths](../../start/learning-paths/index.md). If a term is unfamiliar, look it up in the [Glossary](../glossary/index.md).

**Why does a topic have both an overview page and separate method pages?**
The overview compares the main approaches briefly and links to each one. Each named method has its own page with the problem, core idea, results and limitations. Read the overview first, then the method page that interests you.

**Where can I find courses, books and datasets?**
See [Courses & Books](../courses-books/index.md), [Datasets](../datasets/index.md) and the [Open-Source Resource Survey](../../start/open-source-survey/index.md).

**How do I correct an error or add a page?**
Small fixes can be made with the edit button on any page. For a new page, pick a topic from the Roadmap, follow the [Style Guide](../style-guide/index.md), and read the [Contributing guide](../contributing/index.md).

## Learning AI

**What is the difference between AI, machine learning and deep learning?**
AI is the broad goal of building systems that act intelligently. Machine learning is the part of AI in which systems learn from data rather than following hand-written rules. Deep learning is machine learning with neural networks that have many layers. The [Deep Learning](../../theory/deep-learning/index.md) page builds on these ideas, and the [History of AI](../../start/history/index.md) page shows how they developed.

**Do I need a strong mathematics background?**
Some is needed for the theory sections. Linear algebra, probability and calculus cover most of it. The learning paths indicate which prerequisites each route assumes.

**Which models should I learn first?**
Many current large language models are built on the [Transformer](../../theory/models/transformer/index.md) architecture, which makes it a common starting point. The [Models](../../theory/models/index.md) section surveys the other families.

**Where can I read about the risks and social questions?**
Start with [Safety & Alignment](../../society/safety-alignment/index.md), [Ethics & Fairness](../../society/ethics/index.md) and [Law, Policy & Governance](../../society/governance/index.md).

**Is AI conscious, or can it understand?**
These questions are open. The [Philosophy of AI](../../society/philosophy/index.md) page sets out the main arguments on each side, and the [Brain & Mind](../../brain-mind/index.md) section covers what neuroscience and cognitive science contribute.
