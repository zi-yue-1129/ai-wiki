# Datasets

Widely used datasets, grouped by field. Check each dataset's licence and terms before use.

## Vision

| Dataset | Content |
|---|---|
| MNIST, Fashion-MNIST | 28×28 digits / clothing; teaching |
| CIFAR-10/100 | 32×32 images, 10/100 classes |
| ImageNet-1k | 1.28M images, 1,000 classes |
| COCO | Detection, segmentation, captions |
| Open Images | ~9M images with boxes and labels |
| ADE20K, Cityscapes | Scene parsing, urban driving segmentation |
| LAION-5B / Re-LAION, DataComp | Image–text pairs from the web |
| SA-1B | 1B+ masks (Segment Anything) |

## Language

| Dataset | Content |
|---|---|
| Common Crawl | Raw web crawl |
| C4, The Pile, RedPajama, Dolma, FineWeb / FineWeb-Edu | Filtered pre-training corpora |
| Wikipedia dumps | Encyclopaedic text (CC BY-SA) |
| The Stack | Permissively licensed source code |
| SQuAD, Natural Questions | Question answering |
| GLUE / SuperGLUE | NLU benchmarks (largely saturated) |
| MMLU, GPQA, Humanity's Last Exam | Knowledge and reasoning evaluation |
| GSM8K, MATH | Math word problems |

## Speech and audio

LibriSpeech, Common Voice (many languages, CC0), VoxCeleb, AudioSet, MusicCaps.

## Multimodal and video

Kinetics, Something-Something, Ego4D, HowTo100M, VQAv2, MMMU.

## Robotics and driving

Open X-Embodiment, DROID, nuScenes, Waymo Open Dataset, Argoverse, KITTI.

## Science and health

| Dataset | Content |
|---|---|
| Protein Data Bank (PDB) | Experimental protein structures |
| AlphaFold DB | 200M+ predicted structures |
| UniProt | Protein sequences |
| Materials Project, OQMD | Computed materials properties |
| ERA5 | Global atmospheric reanalysis (weather/climate) |
| MIMIC-III/IV, MIMIC-CXR | ICU records, chest X-rays (credentialed access) |
| CheXpert | Chest X-rays |
| UK Biobank | Genetic, imaging, health data (application required) |
| TCGA | Cancer genomics |
| MoleculeNet, TDC | Molecular ML benchmarks |

## Neuroscience and cognition

| Dataset | Content |
|---|---|
| Natural Scenes Dataset (NSD) | 7T fMRI of people viewing tens of thousands of images |
| Human Connectome Project | Structural and functional brain imaging |
| Allen Brain Observatory | Mouse visual-cortex activity (calcium imaging, Neuropixels) |
| International Brain Laboratory | Standardised mouse decision-making recordings |
| FlyWire | Whole fly-brain connectome |
| MICrONS | Mouse cortex structure + function (cubic millimetre) |
| OpenNeuro, DANDI | Archives of neuroimaging and neurophysiology data |
| Brain-Score benchmarks | Neural and behavioural data for model comparison |
| Psych-101 | Trial-level data from 160 psychology experiments |
| Moral Machine | Millions of moral judgements across cultures |

## Tabular and general ML

UCI Machine Learning Repository, OpenML, Kaggle datasets.
