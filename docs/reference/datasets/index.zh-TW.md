# 資料集

依領域分組的常用資料集。使用前請確認各資料集的授權與使用條款。有連結的資料集名稱指向提出該資料集的論文（或最貼近描述它的論文）。沒有連結的項目尚未找到經過驗證的來源。

## 視覺

| 資料集 | 內容 |
|---|---|
| [MNIST](https://doi.org/10.1109/5.726791)、[Fashion-MNIST](https://arxiv.org/abs/1708.07747) | 28×28 的數字／服飾影像；用於教學 |
| CIFAR-10/100 | 32×32 影像，10／100 個類別 |
| [ImageNet-1k](https://arxiv.org/abs/1409.0575) | 128 萬張影像，1,000 個類別 |
| [COCO](https://arxiv.org/abs/1405.0312) | 偵測、分割、影像說明 |
| [Open Images](https://arxiv.org/abs/1811.00982) | 約 900 萬張附有框與標籤的影像 |
| [ADE20K](https://arxiv.org/abs/1608.05442)、[Cityscapes](https://arxiv.org/abs/1604.01685) | 場景解析、城市駕駛的分割 |
| [LAION-5B](https://arxiv.org/abs/2210.08402)／Re-LAION、[DataComp](https://arxiv.org/abs/2304.14108) | 從網路收集的影像—文字配對 |
| [SA-1B](https://arxiv.org/abs/2304.02643) | 超過 10 億個遮罩（Segment Anything） |
