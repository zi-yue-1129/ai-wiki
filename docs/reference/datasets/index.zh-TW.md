# 資料集

依領域分組的常用資料集。使用前請確認各資料集的授權與使用條款。

## 視覺

| 資料集 | 內容 |
|---|---|
| MNIST、Fashion-MNIST | 28×28 的數字／服飾影像；用於教學 |
| CIFAR-10/100 | 32×32 影像，10／100 個類別 |
| ImageNet-1k | 128 萬張影像，1,000 個類別 |
| COCO | 偵測、分割、影像說明 |
| Open Images | 約 900 萬張附有框與標籤的影像 |
| ADE20K、Cityscapes | 場景解析、城市駕駛的分割 |
| LAION-5B／Re-LAION、DataComp | 從網路收集的影像—文字配對 |
| SA-1B | 超過 10 億個遮罩（Segment Anything） |

## 語言

| 資料集 | 內容 |
|---|---|
| Common Crawl | 原始網路爬取資料 |
| C4、The Pile、RedPajama、Dolma、FineWeb／FineWeb-Edu | 經過過濾的預訓練語料 |
| Wikipedia 傾印檔 | 百科全書式文本（CC BY-SA） |
| The Stack | 採寬鬆授權的原始程式碼 |
| SQuAD、Natural Questions | 問答 |
| GLUE／SuperGLUE | 自然語言理解基準（大多已飽和） |
| MMLU、GPQA、Humanity's Last Exam | 知識與推理評估 |
| GSM8K、MATH | 數學應用題 |

## 語音與聲音

LibriSpeech、Common Voice（多種語言，CC0）、VoxCeleb、AudioSet、MusicCaps。

## 多模態與影片

Kinetics、Something-Something、Ego4D、HowTo100M、VQAv2、MMMU。

## 機器人與自動駕駛

Open X-Embodiment、DROID、nuScenes、Waymo Open Dataset、Argoverse、KITTI。

## 科學與健康

| 資料集 | 內容 |
|---|---|
| Protein Data Bank（PDB） | 實驗測得的蛋白質結構 |
| AlphaFold DB | 超過 2 億個預測結構 |
| UniProt | 蛋白質序列 |
| Materials Project、OQMD | 計算得出的材料性質 |
| ERA5 | 全球大氣再分析（天氣／氣候） |
| MIMIC-III/IV、MIMIC-CXR | ICU 紀錄、胸部 X 光（需具備資格的存取） |
| CheXpert | 胸部 X 光 |
| UK Biobank | 基因、影像與健康資料（需申請） |
| TCGA | 癌症基因組學 |
| MoleculeNet、TDC | 分子機器學習基準 |

## 神經科學與認知

| 資料集 | 內容 |
|---|---|
| Natural Scenes Dataset（NSD） | 受試者觀看數萬張影像時的 7T fMRI |
| Human Connectome Project | 大腦的結構與功能影像 |
| Allen Brain Observatory | 小鼠視覺皮質的活動（鈣離子成像、Neuropixels） |
| International Brain Laboratory | 標準化的小鼠決策記錄 |
| FlyWire | 完整的果蠅腦連結體 |
| MICrONS | 小鼠皮質的結構與功能（立方毫米尺度） |
| OpenNeuro、DANDI | 神經影像與神經生理資料的典藏 |
| Brain-Score 基準 | 用於模型比較的神經與行為資料 |
| Psych-101 | 160 項心理學實驗的試次層級資料 |
| Moral Machine | 跨文化的數百萬筆道德判斷 |
