# Courses & Books

Each entry links to the course or book's own page. Entries marked **(free)** are described as free on that page; others have no free-access claim. See also the [Open-Source Resource Survey](../../start/open-source-survey/index.md).

## Courses

| Topic | Course |
|---|---|
| AI overview | Microsoft [*AI for Beginners*](https://github.com/microsoft/AI-For-Beginners) (MIT licence); Harvard [CS50 AI](https://cs50.harvard.edu/ai/); Berkeley [CS188](https://inst.eecs.berkeley.edu/~cs188/) |
| Machine learning | Andrew Ng, [*Machine Learning Specialization*](https://www.coursera.org/specializations/machine-learning-introduction) (Coursera); Stanford [CS229](https://cs229.stanford.edu/) (lecture notes for Stanford affiliates); Caltech [free introductory machine learning course](https://work.caltech.edu/telecourse) (Abu-Mostafa) |
| Deep learning | [*Dive into Deep Learning*](https://d2l.ai/) (open-source book); [fast.ai](https://course.fast.ai/) (**free**); [MIT 6.S191](http://introtodeeplearning.com/) (materials free); [NYU Deep Learning](https://atcold.github.io/NYU-DLSP21/) (LeCun & Canziani) |
| Vision | Stanford [CS231n](https://cs231n.stanford.edu/) |
| NLP and LLMs | Stanford [CS224n](https://web.stanford.edu/class/cs224n/) (slides and assignments public); Stanford [CS336, Language Modeling from Scratch](https://cs336.stanford.edu/); Hugging Face [LLM course](https://huggingface.co/learn/llm-course) (**free**, no ads) |
| Reinforcement learning | David Silver's [UCL course](https://davidstarsilver.wordpress.com/teaching/) (slides and videos public); OpenAI [Spinning Up](https://spinningup.openai.com/); Berkeley [CS285](https://rail.eecs.berkeley.edu/deeprlcourse/) (lecture slides public) |
| Generative models | Stanford [CS236](https://deepgenerativemodels.github.io/) (notes linked publicly); Hugging Face [Diffusion Models course](https://huggingface.co/learn/diffusion-course) (**free**) |
| Graphs | Stanford [CS224W](https://web.stanford.edu/class/cs224w/) (slides and assignments public) |
| Computational neuroscience | [Neuromatch Academy](https://neuromatch.io/) (open educational materials); [*Neuronal Dynamics* MOOC](https://neuronaldynamics.epfl.ch/) (EPFL, free online book and lectures) |
| NeuroAI | [Neuromatch Academy](https://neuromatch.io/) NeuroAI course |
| Cognitive science | MIT 9.66 *Computational Cognitive Science* (MIT OpenCourseWare); Yale [*Introduction to Psychology*](https://www.coursera.org/learn/introduction-psychology) (Coursera, taught by Paul Bloom) |
| Safety and ethics | [BlueDot AI Safety Fundamentals](https://bluedot.org/?from_site=aisf); CAIS *Introduction to AI Safety, Ethics and Society* (Hendrycks et al.) |
| Mandarin-language | Hung-yi Lee's machine learning and generative AI courses (National Taiwan University); Hsuan-Tien Lin's *Machine Learning Foundations* and *Techniques* courses |

## Books

### General and introductory
- Russell & Norvig, *Artificial Intelligence: A Modern Approach*
- Mitchell, *Artificial Intelligence: A Guide for Thinking Humans*
- Christian, *The Alignment Problem*

### Machine learning and deep learning
- Zhang et al., [*Dive into Deep Learning*](https://d2l.ai/) (free online)
- Prince, *Understanding Deep Learning*
- Goodfellow, Bengio & Courville, [*Deep Learning*](https://www.deeplearningbook.org/) (free online)
- Bishop & Bishop, *Deep Learning: Foundations and Concepts*
- Murphy, [*Probabilistic Machine Learning*](https://probml.github.io/pml-book/book1.html) (free draft, CC BY-NC-ND)
- Hastie, Tibshirani & Friedman, *The Elements of Statistical Learning*
- Sutton & Barto, [*Reinforcement Learning: An Introduction*](http://incompleteideas.net/book/the-book-2nd.html)
- Deisenroth, Faisal & Ong, [*Mathematics for Machine Learning*](https://mml-book.github.io/) (free PDFs)
- Raschka, *Build a Large Language Model (From Scratch)*
- Huyen, *AI Engineering*

### Neuroscience and cognition
- Kandel et al., *Principles of Neural Science*
- Dayan & Abbott, *Theoretical Neuroscience*
- Gerstner et al., [*Neuronal Dynamics*](https://neuronaldynamics.epfl.ch/) (free online)
- Marr, *Vision*
- Lindsay, *Models of the Mind*
- Hawkins, *A Thousand Brains*
- Clark, *Surfing Uncertainty*
- Dehaene, *How We Learn*
- Kahneman, *Thinking, Fast and Slow*
- Griffiths, Chater & Tenenbaum, *Bayesian Models of Cognition*
- Seth, *Being You*

### Society
- Barocas, Hardt & Narayanan, [*Fairness and Machine Learning*](https://fairmlbook.org/) (free online)
- Crawford, *Atlas of AI*
- Acemoglu & Johnson, *Power and Progress*
- Russell, *Human Compatible*
- Hendrycks et al., *Introduction to AI Safety, Ethics, and Society*
