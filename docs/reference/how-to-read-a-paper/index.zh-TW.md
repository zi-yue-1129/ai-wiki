# 如何閱讀 AI 論文

AI 論文篇幅往往很長、內容密集，有時也難以信任。好的閱讀方法能讓人迅速找到核心主張、判斷證據是否支持該主張，並決定這個結果是否值得在其基礎上繼續發展。本頁提供閱讀順序、對基準與實驗應該提出的問題，以及結果能否被重現的跡象。

## 概述

多數機器學習論文都有相似的結構：摘要、說明問題與主張的導論、相關工作、方法、實驗與討論。這個結構是為了方便閱讀，並不保證內容正確。有些論文把關鍵限制藏在附錄中，有些結果則依賴只存在於程式碼中的細節。閱讀方法的目的，就是把作者宣稱的內容與他們真正展示的內容區分開來。

## 關鍵概念

- **主張**：論文希望讀者相信的句子，通常寫在摘要與導論中。
- **證據**：支持主張的實驗，包括設定、資料與指標。
- **基準**：比較用的方法。一個結果的資訊量，取決於它的基準。
- **消融實驗**：移除某個組件，以證明該組件確實有影響的實驗。
- **污染**：訓練期間見過的測試樣本，會使回報的分數虛高。

## 如何閱讀：閱讀順序

分三輪閱讀，而不是從頭到尾線性地讀。

1. **第一輪（約十分鐘）。** 讀標題、摘要、導論與結論。用一句話寫下主張，以及它適用的情境。看圖表與主要結果表。
2. **第二輪（約一小時）。** 讀方法與實驗。檢查實驗是否真的檢驗了主張、基準是否夠強且調校公平、所用的指標是否衡量了主張所需要的東西。閱讀消融實驗，記下它們移除了什麼。
3. **第三輪（僅限重要的論文）。** 重新推導關鍵方程式、重跑部分程式碼，並檢查附錄中的超參數、資料切分與失敗的設定。

在第一、二輪表現良好的論文，第三輪仍可能發現錯誤，因此開始前就應決定你要讀到哪一步。

## 應該提出的問題

- 主張是否只對作者測試的設定成立？摘要是否暗示了更廣的適用範圍？
- 基準是否新、調校是否良好，且在相同的運算預算下執行？弱的基準會讓任何方法看起來都很好。
- 結果是否平均了多個隨機種子，並報告了變異程度？
- 測試集是否與調校用的資料分開？預訓練時是否見過任何測試樣本？
- 論文是否報告了負面結果，例如方法失敗的設定？
- 相較於多次執行之間的變異，回報的進步幅度是否夠大？

## 可重現性的訊號

好的訊號包括隨論文釋出的程式碼與資料、精確的超參數、所用的運算資源，以及清楚的資料切分說明。警訊包括只報告單一數字的結果、缺少消融實驗，以及只用文字描述、無法依文字實作的方法。

容易找到這些訊號的論文不一定正確，但會更容易檢驗。Lipton 與 Steinhardt 討論了機器學習文獻中的常見問題，包括未經證明的主張、把解釋與臆測混為一談，以及在無益處的地方使用數學 [(Lipton and Steinhardt, 2018)](https://arxiv.org/abs/1807.03341)。Pineau 等人報告了 NeurIPS 2019 可重現性計畫，該計畫涵蓋什麼樣的結果才算可靠且可重現 [(Pineau et al., 2020)](https://arxiv.org/abs/2003.12206)。

## 實例

Transformer 論文是很好的練習材料。它的主張是，只用注意力的架構可以取代序列轉換中的遞迴與卷積。它的證據是一組機器翻譯實驗，最主要的結果是 WMT 2014 英譯德的 BLEU 為 28.4，摘要說明這比包括集成模型在內的先前最佳結果高出超過 2 個 BLEU [(Vaswani et al., 2017)](https://arxiv.org/abs/1706.03762)。仔細的讀者會問：哪些基準調校到同等程度？結果能否推廣到翻譯以外的任務？訓練成本是多少？這篇論文後來的影響力，並不能回答這些問題。

## 應用

學生用閱讀方法準備研討會或文獻回顧。實務工作者用它判斷是否採用某個方法。審稿人用它檢查投稿論文的主張是否有證據支持。

## 開放問題

- 哪些可重現性檢查，能最好地預測結果在實務中能否成立？
- 讀者應如何權衡一個方法的影響力與其證據的強度？
- 自動化工具能否幫助讀者找出遺漏的基準與未報告的變異，同時又不取代判斷？

## 參考文獻

### 重要論文

- Keshav，*How to Read a Paper*，ACM SIGCOMM Computer Communication Review（2007）。https://doi.org/10.1145/1273445.1273458 — 研究論文的三輪閱讀方法，源自電腦系統領域，但廣泛用於其他領域。
- Lipton 與 Steinhardt，*Troubling Trends in Machine Learning Scholarship*（2018）。https://arxiv.org/abs/1807.03341 — 整理機器學習論文的常見問題，以及它們如何扭曲文獻。
- Pineau、Vincent-Lamarre、Sinha、Larivière、Beygelzimer、d'Alché-Buc、Fox 與 Larochelle，*Improving Reproducibility in Machine Learning Research (A Report from the NeurIPS 2019 Reproducibility Program)*（2020）。https://arxiv.org/abs/2003.12206 — 報告可重現性計畫及其實務建議。
- Vaswani 等人，*Attention Is All You Need*（2017）。https://arxiv.org/abs/1706.03762 — 上文實例所使用的論文。
