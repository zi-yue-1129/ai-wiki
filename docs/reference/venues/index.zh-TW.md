# 會議與期刊

AI 研究在哪裡發表、主要場所有何不同，以及如何解讀場所的名稱。以下列出本維基最常引用的場所。每個連結都指向該場所的官方網站或其論文集檔案。

## 機器學習與 AI 會議

| 場所 | 涵蓋範圍 | 論文在哪裡 |
|---|---|---|
| [NeurIPS](https://proceedings.neurips.cc/) | 神經資訊處理系統，涵蓋機器學習與計算神經科學 | 論文集檔案，自 1987 年起（早期名稱為 NIPS） |
| [ICML](https://icml.cc/) | 國際機器學習大會（International Conference on Machine Learning） | 大會網站 |
| [ICLR](https://iclr.cc/) | 表徵學習，包括深度學習及其應用 | 大會網站 |
| [CVPR](https://cvpr.thecvf.com/) | 電腦視覺與模式辨識 | 大會網站 |
| [ACL](https://aclanthology.org/) | 計算語言學與語言技術；ACL Anthology 收錄 ACL 場所及相關研究 | ACL Anthology |
| [AAAI](https://aaai.org/) | 較廣義的人工智慧；舉辦會議並出版論文集 | AAAI 論文集 |

這些會議對本維基中受神經科學啟發的主題很重要，這些主題常先在這裡發表，之後才出現在主要的 AI 會議上。

## 預印本與開放平台

[arXiv](https://arxiv.org/about) 由 Paul Ginsparg 於 1991 年創立，是分享研究的開放平台，目前收錄近兩百萬篇跨物理、數學、電腦科學等領域的論文。許多 AI 論文會先或同時出現在 arXiv 上，因此論文的 arXiv 版本通常最容易找到。

[OpenReview](https://openreview.net/) 是促進研究分享與審查透明化的平台。它承載包括會議與期刊在內的學術場所，並讓部分場所的審查意見公開。

## 審查流程

同儕審查可以是單盲，審稿人看得到作者姓名；也可以是雙盲，審稿人看不到。兩種模式可能造成不同的審稿行為。[Tomkins 等人（2017）](https://doi.org/10.1073/pnas.1707323114) 研究了單盲與雙盲審查下的審稿偏誤，這關係到場所的決定能在多大程度上被視為品質的衡量。

## 如何解讀場所名稱

- 場所名稱說明的是主題領域與研究社群，本身並不是品質等級。
- 場所在涵蓋範圍、審查政策與論文開放程度上各不相同。依賴某個場所的流程之前，請先查看該場所的官方網站。
- 有些優秀的研究會先出現在 arXiv、工作坊或專門的場所，因此論文沒有登上頂尖會議，並不代表它的品質較差。
