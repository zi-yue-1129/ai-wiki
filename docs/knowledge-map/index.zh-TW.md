# 知識地圖

以頁面本身繪製的整個知識庫地圖。每個圓圈是一個主題，顏色表示該頁面的完成程度。兩個主題若彼此指向對方（相關主題，或內文中的連結），中間就會有一條線，因此能看出醫療、法律、機器人等領域如何與它們所用的模型與概念相連。

地圖會在網站建置時自動產生，所以新增頁面、加入連結或完成頁面後都會同步更新。點選任一圓圈即可開啟該頁面，也可以在下方展開各領域查看更細的地圖。

## 如何閱讀

- **群組**代表領域。主題會被拉向所屬的領域，而不同領域之間的連結則把它們拉在一起。
- **密集的結點**是許多其他頁面都會提到的主題，例如數學與學習理論相關頁面。
- **孤立的圓圈**是目前沒有其他頁面連結到它的主題。在前言的相關主題或內文中加入連結，即可把它接上地圖。
