# 知識地圖

整個知識庫中的主題，全部由頁面本身繪製。地圖一開始只顯示五大領域，點選領域即可看到其中的群組，再點選群組就能看到各個主題。每個主題是一個圓圈，顏色代表所屬的領域，空心圓圈表示草稿頁面。兩個主題若彼此指向對方（相關主題，或內文中的連結），中間就會有一條線，因此能看出醫療、法律、機器人等領域如何與它們所用的模型與概念相連。

地圖會在網站建置時自動產生，所以新增頁面、加入連結或完成頁面後都會同步更新。

## 如何使用

- **移動地圖**：拖曳可平移，滾輪或雙指捏合可縮放，也可以使用地圖上方的按鈕放大、縮小或符合畫面。
- **全螢幕**：點選工具列上的全螢幕按鈕，地圖會放大到整個畫面，按 Esc 即可離開。
- **搜尋主題**：在搜尋框輸入關鍵字，點選結果後，地圖會打開該主題所在的群組，並把它置中。
- **標籤**：放大地圖或把游標移到圓圈上時會顯示名稱；點選圓圈會突顯與它相連的主題。
- **清單**：地圖下方的清單以純文字連結列出同樣的主題，方便在手機上閱讀或搜尋。
