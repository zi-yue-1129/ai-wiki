# 倫理與公平

## 共通原則

多數 AI 倫理框架（OECD AI 原則、UNESCO《人工智慧倫理建議書》、IEEE、企業的原則）都趨向於：**行善、不作惡、自主、正義／公平、可說明性**，外加隱私、問責與永續（Floridi & Cowls, 2019；Jobin et al., 2019）。困難之處在於把原則落實為實務。

## 偏見與公平

### 偏見從何而來

| 來源 | 例子 |
|---|---|
| 歷史偏見 | 過去的招聘資料反映了歧視（亞馬遜於 2018 年棄用的履歷篩選系統） |
| 代表性偏見 | 訓練資料中某些群體代表性不足（臉部分析對深膚色女性的錯誤率高得多——Buolamwini & Gebru, 2018，"Gender Shades"） |
| 測量偏見 | 代理目標在不同群體間意義不同（以醫療花費代替需求——Obermeyer et al., 2019） |
| 聚合偏見 | 對彼此關係不同的群體使用同一個模型 |
| 部署偏見 | 把模型用在設計時未考慮的情境 |
| 回饋迴路 | 預測性警政把巡邏派往過去逮捕較多的地點，進而產生更多逮捕 |

### 公平性的定義

| 準則 | 要求 |
|---|---|
| 人口統計均等 | 各群體的陽性預測率相同 |
| 機會均等化（equalised odds） | 真陽性率與偽陽性率相同 |
| 機會平等 | 真陽性率相同 |
| 預測均等／校準 | 精確率相同；分數在各群體中的意義一致 |
| 個體公平 | 相似的個體受到相似的對待 |
| 反事實公平 | 若受保護屬性不同，預測結果不變 |

**不可能性結果**：當基礎比率不同時，校準與相等的錯誤率一般無法同時成立（Kleinberg, Mullainathan & Raghavan, 2016；Chouldechova, 2017）——這正是 COMPAS 爭議的核心。選擇哪種準則是價值判斷，而不是技術判斷。

詳細的定義與不可能性證明見[公平性定義與不可能性結果](fairness-definitions.md)。

### 緩解

前處理（重新加權、重新抽樣）、處理中（公平性約束）、後處理（依群體設定門檻），最重要的還有：更好的問題定義、資料，以及利害關係人的參與。工具：Fairlearn、AIF360。

### LLM 中的偏見

生成文字與影像中的刻板印象、方言偏見（例如對非裔美國人英語的隱性偏見，Hofmann et al., 2024, *Nature*）、不同語言之間表現的不平等，以及預設採用西方規範的文化偏誤。

具體案例（包括 COMPAS、Gender Shades 與健康風險演算法）見[演算法偏見案例研究](bias-case-studies.md)。

## 隱私

- 以從網路爬取的個人資料進行訓練；記憶與萃取
- 從看似無害的資料推斷敏感屬性
- 監控：公共場所的臉部辨識（歐盟 AI 法有所限制）
- 權利：GDPR 的查閱、刪除與拒絕權；從已訓練模型中「遺忘」的困難
- 技術：[聯邦式學習、差分隱私](../../theory/paradigms/federated/index.md)

## 問責與透明

- 當 AI 輔助的決策傷害了某人，誰該負責？開發者、部署者，還是使用者？
- 文件（模型卡、資料表、系統卡）、稽核與影響評估
- 可爭議性：人們應能挑戰自動化的決策

稽核與文件實務見[演算法稽核與影響評估](algorithmic-auditing.md)。
