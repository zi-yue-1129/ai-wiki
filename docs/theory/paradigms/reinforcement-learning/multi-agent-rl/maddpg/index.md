# MADDPG (Lowe et al., 2017)

MADDPG is an actor-critic method for [multi-agent reinforcement learning](../index.md) in which each agent has its own policy, which sees only its local observation, and its own critic, which sees the actions of all agents during training. Because each critic conditions on the others' actions, the environment looks stationary to every learner, and the method works with cooperative, competitive and mixed rewards.

## Overview

Independent actor-critic learners fail in the multi-agent setting for two reasons, as Lowe et al. (2017) explain. Q-learning is challenged by the non-stationarity of an environment in which other agents keep changing, and policy gradient methods suffer from variance that grows with the number of agents. MADDPG keeps the policy-gradient approach but gives each critic the information it needs to account for the other agents. The method builds on DDPG (Lillicrap et al., 2015), a deterministic actor-critic for continuous actions, which it extends to several agents. It is an instance of the centralised-training idea described on the [parent topic page](../index.md).

## Key concepts

- **Deterministic actor**: agent $i$ has a policy $\mu_i(o_i)$ that maps its own observation $o_i$ to an action.
- **Centralised critic**: agent $i$ has a value function $Q_i^\mu(x, a_1, \dots, a_N)$ that takes the global information $x$ and every agent's action.
- **Policy ensemble**: each agent trains several policies and samples one at the start of each episode. This makes an agent less likely to overfit to the current policies of its opponents.
- **Mixed rewards**: each agent maximises its own reward, so the method does not assume a shared team reward.

## How it works

For agent $i$, the actor is updated by the gradient

$$
\nabla_{\theta_i} J(\mu_i) = \mathbb{E}\Big[\nabla_{\theta_i}\mu_i(o_i)\, \nabla_{a_i} Q_i^{\mu}(x, a_1, \dots, a_N)\big|_{a_i = \mu_i(o_i)}\Big],
$$

so the critic's estimate of how the agent's own action affects its return tells the actor which way to move. The critic minimises a temporal-difference loss:

$$
L(\phi_i) = \mathbb{E}\big[(Q_i^{\mu}(x, \mathbf{a}) - y)^2\big], \qquad y = r_i + \gamma\, Q_i^{\mu'}(x', \mu'_1(o'_1), \dots, \mu'_N(o'_N)),
$$

where $\mu'$ denotes target policies. The steps are:

1. Initialise each agent's actor and critic, their target copies, and a replay buffer of joint transitions.
2. At the start of each episode, each agent samples one policy from its ensemble and acts with exploration noise.
3. Store the joint transition $(x, \mathbf{a}, r, x')$ in the buffer.
4. Sample a minibatch and update each critic with the loss above, using the target actions of all agents.
5. Update each actor with the gradient above, using its critic.
6. Move the target networks slowly toward the learned networks.

## Results

The paper evaluates MADDPG on a set of multi-agent particle environments, which include tasks that need coordination, such as navigation and communication, and tasks that set agents against one another, such as predator and prey. According to the abstract, the approach is stronger than existing methods in both cooperative and competitive scenarios, and agent populations discover coordination strategies in both physical and informational forms. The comparison numbers are in the paper.

## Limitations

- **Training needs all actions.** The critic requires the actions of every agent during training. The input size grows with the number of agents, and the information may not be available in real deployments.
- **Continuous actions.** The deterministic policy gradient is designed for continuous action spaces.
- **Stale replay.** Joint transitions stored in the buffer were generated by older versions of the other agents' policies, which weakens the training signal.
- **Ensembles are heuristic.** Sampling from a policy ensemble reduces overfitting to specific opponents but does not guarantee robustness to a new one.

## Open questions

Can a critic scale to many agents without losing its ability to account for them? Mean-field approximations, which replace the other agents with their average effect (Yang et al., 2018), suggest one route, but the trade-off is not settled. A second question is how to avoid needing the other agents' true actions at all. [QMIX](../qmix/index.md) takes a different route, factorising the joint value. Lanctot et al. (2017) propose training against mixtures of policies to reduce overfitting to the latest opponent.

## References

### Seminal papers

- Lowe, R. et al. (2017). *Multi-Agent Actor-Critic for Mixed Cooperative-Competitive Environments*. arXiv:1706.02275. https://arxiv.org/abs/1706.02275 — The MADDPG paper, with centralised critics, policy ensembles and experiments on cooperative and competitive tasks.
- Lillicrap, T. P. et al. (2015). *Continuous control with deep reinforcement learning*. arXiv:1509.02971. https://arxiv.org/abs/1509.02971 — DDPG, the single-agent deterministic actor-critic that MADDPG extends to several agents.
- Foerster, J. et al. (2017). *Counterfactual Multi-Agent Policy Gradients*. arXiv:1705.08926. https://arxiv.org/abs/1705.08926 — COMA, another centralised-critic method, which uses a counterfactual baseline in place of per-agent critics.
- Lanctot, M. et al. (2017). *A Unified Game-Theoretic Approach to Multiagent Reinforcement Learning*. arXiv:1711.00832. https://arxiv.org/abs/1711.00832 — Shows that independent learners overfit to each other and proposes training against mixtures of policies.

### Surveys and textbooks

- Hernandez-Leal, P., Kartal, B. & Taylor, M. E. (2018). *A Survey and Critique of Multiagent Deep Reinforcement Learning*. arXiv:1810.05587. https://arxiv.org/abs/1810.05587 — Survey of deep MARL, including the actor-critic methods to which MADDPG belongs.

### Articles and documentation

- Yang, Y. et al. (2018). *Mean Field Multi-Agent Reinforcement Learning*. arXiv:1802.05438. https://arxiv.org/abs/1802.05438 — Approximates the interactions among a large population by the interaction with its average, to make learning tractable.
- Papoudakis, G. et al. (2020). *Benchmarking Multi-Agent Deep Reinforcement Learning Algorithms in Cooperative Tasks*. arXiv:2006.07869. https://arxiv.org/abs/2006.07869 — Empirical comparison of MARL families on common cooperative tasks, with the code released as EPyMARL.
