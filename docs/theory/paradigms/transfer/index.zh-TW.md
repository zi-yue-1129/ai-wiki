# 遷移學習與領域適應

## 概念

把在**來源**任務或領域學到的知識，重用到**目標**任務或領域，以較少資料做得更好。現在幾乎所有實務模型都從預訓練網路開始。

## 類型

| 類型 | 來源 vs 目標 | 例子 |
|---|---|---|
| 歸納式遷移（微調） | 不同任務，目標有標註資料 | ImageNet 模型 → 皮膚病灶分類器 |
| 轉導式／領域適應 | 同一任務，輸入分布不同，目標很少或沒有標籤 | 合成影像 → 真實影像；某醫院的掃描儀 → 另一家醫院 |
| 多任務學習 | 同時學習多個任務 | 偵測與分割共用編碼器 |
| 跨語言遷移 | 用一種語言訓練，用在另一種 | 多語模型以低資源語言回答 |
| 模擬到真實 | 模擬 → 實體世界 | 在模擬中訓練的機器人步行 |
| 零樣本遷移 | 完全不在目標上訓練 | CLIP 依文字名稱分類新類別 |

## 微調策略

| 策略 | 訓練什麼 | 何時用 |
|---|---|---|
| 線性探測 | 只訓練新的輸出頭 | 資料極少；診斷表徵品質 |
| 完整微調 | 全部權重 | 資料與算力足夠 |
| 漸進解凍／分層學習率 | 先訓練後面的層，前面層用較小學習率 | ULMFiT 式 |
| 參數高效微調（PEFT） | Adapter、LoRA、prefix/prompt tuning | 大模型、多任務 |
| 提示／上下文學習 | 不訓練——在輸入中描述任務 | 基礎模型 |

見 [訓練與微調](../../../engineering/training/index.md)。

## 分布偏移的分類

- **共變量偏移**：\(p(x)\) 改變，\(p(y\mid x)\) 不變
- **標籤（先驗）偏移**：\(p(y)\) 改變（不同診所的盛行率不同）
- **概念偏移**：\(p(y\mid x)\) 改變（什麼算垃圾信會演變）

領域適應方法：重要性重加權、特徵對齊（MMD、CORAL）、領域對抗訓練（DANN）、在目標上自我訓練、測試時適應、資料增強與領域隨機化。

## 負遷移

來源與目標差太多時，遷移反而有害。務必和從零訓練的基準比較，尤其在醫療、衛星、科學資料等特殊領域，領域專屬的預訓練常勝過一般的 ImageNet 或網路預訓練。

## 人類認知中的遷移

- **近遷移 vs 遠遷移**：學習很容易遷移到相似問題，但很少遷移到差距大的問題——教育心理學的穩健發現（例如「大腦訓練」遊戲會提升被訓練的任務，但遠遷移很少；Simons et al., 2016）
- **類比推理**（Gentner 的結構映射理論）是遠遷移的認知機制：把已知領域的關係結構映射到新領域
- **神經再利用**：腦區會被回收用於新的文化技能——閱讀所用的視覺字形區（Dehaene 的「神經元回收」）是微調預訓練網路的生物對應
