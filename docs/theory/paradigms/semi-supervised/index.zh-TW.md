# 半監督與弱監督學習

標籤常常是瓶頸：放射科醫師的一小時很貴，但未標註的影像很多。這兩種範式要從有限或不完美的監督中榨出更多價值。

## 半監督學習

**情境**：少量標註集 \(D_L\) 加上大量來自相同分布的未標註集 \(D_U\)。

**讓它有效的假設**：

- **平滑性**：相近的點有相同標籤
- **群集假設**：決策邊界通過低密度區域
- **流形假設**：資料位於低維流形上

| 方法 | 想法 |
|---|---|
| 自我訓練／偽標籤 | 用 \(D_L\) 訓練，給 \(D_U\) 中有信心的點貼標籤，再重新訓練 |
| 共同訓練 | 兩個模型在不同特徵視角上互相標註 |
| 一致性正規化 | 擾動下預測應保持穩定（Π-model、Mean Teacher、UDA） |
| FixMatch 及後繼方法 | 對弱增強的影像產生偽標籤，訓練強增強版本去符合它 |
| 圖上的標籤傳播 | 在相似度圖上擴散標籤 |
| 生成式方法 | 半監督 VAE、GAN |
| 先預訓練再微調 | 在 \(D_U\) 上自監督預訓練＋在 \(D_L\) 上監督微調——現今主流做法 |

Noisy Student（Xie et al., 2020）顯示，用更大且加入雜訊的學生模型做自我訓練，可以提升 ImageNet 準確率與穩健性。

## 弱監督學習

**情境**：有標籤，但有雜訊、粗略、間接或不完整。

| 類型 | 例子 | 方法 |
|---|---|---|
| 不精確（粗略） | 只有影像層級的「有腫瘤」標籤，卻需要像素遮罩 | 多實例學習、類別啟動圖 |
| 不準確（有雜訊） | 群眾標註有錯 | 抗雜訊損失、標籤雜訊建模、co-teaching |
| 不完整 | 只標了部分正例 | PU 學習（見 [其他範式](../other/index.md)） |
| 程式化 | 啟發式標註函數 | 資料程式設計（Snorkel）結合多條有雜訊的規則 |
| 遠端監督 | 把文字和知識庫對齊來標註關係 | 關係抽取 |
| 自然語言監督 | 網路上的圖片—說明文字配對 | CLIP：網路規模的弱監督 |

病理全玻片影像是典型例子：數十億像素的玻片只有玻片層級的診斷，以注意力式多實例學習處理（Ilse et al., 2018；Campanella et al., 2019）。

## 實務建議

1. 先用強大的預訓練模型，常常勝過複雜的半監督技巧
2. 確認未標註資料真的來自相同分布，否則偽標籤會強化錯誤
3. 對信心度做校準後再設閾值
4. 保留乾淨的專家標註測試集；絕不用偽標籤評估

## 與人類學習的對照

兒童得到的明確標籤（「那是狗」）遠少於他們吸收的未標註經驗。半監督類別學習研究（例如 Zhu et al., 2007〈Humans perform semi-supervised classification too〉）顯示，未標註的例子會依群集假設預測的方向移動人類的類別邊界。
