# 知識蒸餾

知識蒸餾訓練一個小型的**學生**模型，使其重現大型**教師**模型的行為。學生從教師的輸出機率或內部表徵學習，而不只從標籤學習，因此即使架構相同，它往往能達到直接用資料訓練時達不到的準確度。

## 概述

蒸餾是[模型壓縮](../index.zh-TW.md)的一個家族。與[量化](../quantisation/index.zh-TW.md)和[剪枝](../pruning/index.zh-TW.md)不同，它不會原地修改大模型，而是產生一個新的、較小的模型，學生的架構也可以與教師不同。

這個想法的前提是：訓練好的網路，其輸出分布所承載的資訊比最高機率的預測還多。如果分類器認為一張狗的影像有少量機率是貓，極少機率是卡車，這些相對數值就揭示了類別之間的關係。Hinton 等人（2015）稱這種資訊為**暗知識**。

## 關鍵概念

- **軟目標。** 教師的輸出在比較前先以溫度 \(T\) 軟化，使小機率不會淹沒在雜訊中：\(p_i = \exp(z_i/T) / \sum_j \exp(z_j/T)\)。
- **溫度。** 較高的 \(T\) 會攤平機率，讓學生得到更多關於類別之間關係的資訊。損失通常乘以 \(T^2\)，以維持梯度大小相近。
- **以回應為基礎與以特徵為基礎。** 以回應為基礎的蒸餾比對輸出分布；以特徵為基礎的蒸餾比對中間表徵，使學生不只學到輸出什麼，也學到教師如何計算。
- **序列層級蒸餾。** 對語言模型而言，教師生成完整的輸出，學生把它當作一般監督資料來訓練。這是語言模型的重要方法之一，其他方法還包括 token 層級的機率匹配及合成資料訓練。
- **教師品質。** 教師的弱點與偏誤可能傳遞給學生，但教師表現不是學生表現的嚴格上界；架構、正則化、資料及評估條件也會影響結果。

## 運作方式

Hinton 等人以加權平均結合兩種損失。學生以真實標籤的交叉熵項訓練，並以教師軟化輸出的項訓練，該項乘以 \(T^2\)，使溫度改變時梯度的大小大致保持不變。下式把軟目標項寫成 KL 散度，它與交叉熵只相差一個常數。權重 \(\alpha\) 平衡兩者：

\[
\mathcal{L} = (1-\alpha)\, \mathrm{CE}(y, \sigma(z_s)) + \alpha\, T^2\, \mathrm{KL}\!\left(\sigma(z_t/T)\,\Vert\,\sigma(z_s/T)\right)
\]

其中 \(z_s\) 與 \(z_t\) 分別是學生與教師的 logits，\(\sigma\) 是 softmax。教師是凍結的，因此其輸出可以預先算好，也可以即時生成。

對語言模型，同樣的想法應用在 token 層級，或應用在教師生成的整段序列上。蒸餾得到的模型通常會在比原教師監督階段更多的資料上訓練，但教師推論仍有成本，生成資料也可能有偏或錯誤。token 層級蒸餾還需要教師機率分布，僅提供文字輸出的 API 未必能支援。

## 代表方法

以下方法的差異在於學生模仿的監督訊號；詳細演算法、實驗與限制請參考各自的子頁面。

- [Hinton 蒸餾（Hinton 等人，2015）](response-based/hinton-distillation/index.zh-TW.md)：結合真實標籤與溫度軟化後的教師機率。
- [FitNets（Romero 等人，2014）](feature-based/fitnets/index.zh-TW.md)：透過映射層對齊較窄學生網路與教師中間層表徵。
- [DistilBERT（Sanh 等人，2019）](response-based/distilbert/index.zh-TW.md)：在預訓練階段結合語言模型、蒸餾及餘弦距離損失。
- [序列層級蒸餾（Kim 與 Rush，2016）](llm-distillation/sequence-level/index.zh-TW.md)：使用教師解碼出的完整序列訓練學生。

## 方法家族比較

| 家族 | 學生所匹配的內容 | 代表方法 | 頁面 |
| --- | --- | --- | --- |
| 以回應為基礎 | 經溫度軟化的輸出分布 | Hinton 蒸餾、DistilBERT、助教蒸餾 | [以回應為基礎](response-based/index.zh-TW.md) |
| 以特徵為基礎 | 中間激活值或注意力圖 | FitNets、注意力轉移 | [以特徵為基礎](feature-based/index.zh-TW.md) |
| 以關係為基礎 | 批次中樣本之間的關係 | RKD、相似度保持 | [以關係為基礎](relation-based/index.zh-TW.md) |
| 自我蒸餾 | 網路自己的早期副本或較深的層 | 重生網路、做你自己的老師 | [自我蒸餾](self-distillation/index.zh-TW.md) |
| 無資料 | 教師在合成或生成輸入上的輸出 | 零樣本 KD | [無資料](data-free/index.zh-TW.md) |
| 大型語言模型蒸餾 | 生成的文字、學生自己的樣本，或推理軌跡 | 序列層級 KD、MiniLLM、DeepSeek-R1 | [大型語言模型蒸餾](llm-distillation/index.zh-TW.md) |

以回應為基礎的蒸餾是基準，也是實務上最常見的形式。其他家族則加入來自教師內部、關係或生成資料的訊號，代價是更多的設計選擇與更多的運算。

## 實際算例：溫度與軟目標

假設教師對三個類別的 logits 為 \(z_t=[4,2,0]\)。當 \(T=1\) 時，softmax 約為 \([0.867,0.117,0.016]\)；當 \(T=2\) 時，則約為 \([0.665,0.245,0.090]\)。最高機率類別不變，但其他類別對學習訊號的貢獻增加。這不代表溫度愈高愈好。

上方 KL 散度以教師分布作為目標；交換兩個引數會改變最佳化問題。乘上 \(T^2\) 是在高溫近似下補償梯度縮小的慣用方法，不保證所有 logits 的梯度都與溫度無關。調整損失權重時，應分別記錄硬標籤與軟標籤損失。

可重現的實驗應先凍結教師，針對學生實際看到的輸入計算教師目標，最佳化組合損失，再使用獨立驗證集選擇 checkpoint。若預先快取教師 logits，必須說明資料增強是否改變輸入：某次影像裁切的快取目標，不一定適用於另一個裁切。

## 評估協定

模型壓縮必須同時報告品質與部署成本。至少比較凍結教師，以及「相同學生架構但未使用蒸餾」的基準，並確保訓練預算可比較。除了任務指標，也應記錄參數量、記憶體、吞吐量，以及指定硬體、batch size 與精度下的延遲；參數較少不代表推論一定更快。

分類任務除了平均準確率，還應檢查校準及各類別錯誤；生成任務則需記錄解碼設定、輸出長度、任務指標及教師生成資料的比例。學生可能保留基準分數，卻繼承教師的系統性錯誤，或改變不確定性估計。測試集不可混入提示詞選擇、合成標籤生成或超參數調整流程。

最後應區分離線教師成本（推論查詢、GPU 時間、目標儲存）與線上學生成本。蒸餾是否划算取決於部署推論量及原本的服務配置。Gou 等人（2021）綜述了不同知識類型與訓練方式。

## 取捨

- **大小與品質。** 較小的學生會失去能力，尤其是在需要教師更廣泛知識的任務上。
- **教師的成本。** 蒸餾需要大量的教師前向計算。這筆成本只付一次，之後分攤到學生的每次使用上。
- **架構自由與知識轉移。** 學生可以使用比教師更快的架構，但兩者差異很大時，知識轉移會更困難。
- **授權與資料。** 用專有模型的輸出訓練學生，可能受該供應商使用條款限制，各家不同。

## 相關連結

蒸餾是一種訓練技術，因此它位於[訓練](../../../engineering/training/index.zh-TW.md)頁與決定要服務哪個模型的 [MLOps](../../../engineering/mlops/index.zh-TW.md) 頁之間。[大型語言模型](../../models/llm/index.zh-TW.md)頁把蒸餾列為降低成本與延遲的方法之一。

從教師的分級判斷學習，而不是從標準答案學習，與人類的學習有相似之處。老師、家長與同儕給的分級回饋，承載的資訊超過正確答案本身。大腦是否使用類似的機制仍是開放問題；見[認知科學](../../../brain-mind/cognitive-science/index.zh-TW.md)。

## 應用

- **行動與嵌入式模型**：在產品中以蒸餾後的學生取代大型模型。
- **語言模型家族**：從較大的同系模型蒸餾出較小的模型，作為較便宜的選項。
- **推理模型**：用較強模型產生的推理軌跡，訓練較小的模型以遵循相同步驟。
- **語音與視覺系統**：從集成或大型模型蒸餾，在不改變架構的情況下改善已部署的模型。

## 開放問題

- **什麼知識會被轉移。** 學生較容易匹配輸出，而不是內部推理。如何轉移教師解決問題的過程，目前還沒有定論。
- **教師的限制。** 學生在特定評估上可能超越教師，但教師錯誤與資料選擇仍限制知識轉移。如何可靠選擇教師與資料仍待研究。
- **自我蒸餾。** 模型從自己的早期版本蒸餾後可以改進，但為什麼有效尚未完全解釋。
- **評估。** 學生在基準上可能與教師相當，但在校準、穩健性或失敗模式上有所不同。

## 參考文獻

### 開創性論文

- Hinton, G., Vinyals, O., Dean, J. (2015). *Distilling the Knowledge in a Neural Network*. arXiv:1503.02531. https://arxiv.org/abs/1503.02531 — 介紹軟目標與溫度。摘要描述的是把集成模型的知識壓縮成一個較易部署的單一模型。
- Sanh, V., Debut, L., Chaumond, J., Wolf, T. (2019). *DistilBERT, a Distilled Version of BERT: Smaller, Faster, Cheaper and Lighter*. arXiv:1910.01108. https://arxiv.org/abs/1910.01108 — 蒸餾後的 BERT，體積小 40%、速度快 60%，並保留教師 97% 的語言理解能力。
- Romero, A., 等人 (2014). *FitNets: Hints for Thin Deep Nets*. arXiv:1412.6550. https://arxiv.org/abs/1412.6550 — 以教師的中間層提示訓練較窄的深層學生。在 CIFAR-10 上，參數約少 10.4 倍的學生勝過更大的先進教師網路。
- Kim, Y., Rush, A. M. (2016). *Sequence-Level Knowledge Distillation*. arXiv:1606.07947. https://arxiv.org/abs/1606.07947 — 以教師輸出訓練序列模型，學生速度約為教師的 10 倍，效能損失很小。

### 綜述與教科書

- Gou, J., 等人 (2021). *Knowledge Distillation: A Survey*. International Journal of Computer Vision, 129, 1789–1819. https://doi.org/10.1007/s11263-021-01453-z — 依知識類型、訓練方式、架構與應用綜述知識蒸餾。
