# BERT

BERT（Bidirectional Encoder Representations from Transformers，雙向編碼器表示）是一種編碼器專用的 [Transformer](../../index.md)，以同時來自左右兩側的上下文預測被遮蓋的 token 進行預訓練。Devlin 等人（2019）證明，一個預訓練模型只要加上單一輸出層進行微調，就能在多種語言任務上達到最先進的結果。它是[架構家族](../index.md)概覽中編碼器專用家族的代表。

## 概述

在 BERT 之前，多數預訓練語言模型都是由左至右讀取文字。由左至右的模型只能使用某位置之前的詞，這限制了它從上下文學到一個詞的能力。BERT 一次讀入整段序列，因此每一層中每個位置都能關注其他所有位置。它的預訓練任務會遮住一部分 token，要求模型把它們復原，如此便能使用雙向上下文，而不會洩漏答案。

論文主張，這種設計使預訓練的表示能在很少的任務專屬架構下用於許多任務。預訓練與微調使用同一個網路，只有輸出層會改變。

## 關鍵概念

- **WordPiece token**：輸入被切分成的子詞單位。預訓練中的遮蓋即套用在這些 token 上。
- **遮蓋語言模型（MLM）**：根據上下文預測被隱藏 token 的預訓練任務。
- **特殊 token**：\[CLS\] 放在每個序列的開頭，其最終狀態用於句子層級的預測。\[SEP\] 用來分隔兩個句子。
- **段落嵌入（segment embedding）**：加到每個 token 上的可學習嵌入，用來標示該 token 屬於句子 A 或句子 B。
- **模型尺寸**：BERT-Base 有 12 層、隱藏維度 768、12 個注意力頭，約 110M 參數。BERT-Large 有 24 層、隱藏維度 1024、16 個注意力頭，約 340M 參數。

## 運作方式

每個 token 的輸入是三種嵌入的總和：WordPiece 嵌入、位置嵌入與段落嵌入。接著序列通過一疊具雙向自注意力的 Transformer 編碼器區塊。

預訓練時，每個序列中 15% 的 WordPiece token 被隨機選取。其中 80% 替換為 \[MASK\]，10% 替換為隨機 token，10% 保持不變。模型預測每個被選取位置的原始 token，因此損失只計算這些位置上的交叉熵：

\[
\mathcal{L}_{\text{MLM}} = -\sum_{i \in M} \log p_\theta\big(x_i \mid \tilde{x}\big)
\]

其中 \(M\) 是被選取位置的集合，\(\tilde{x}\) 是被破壞後的輸入。80/10/10 規則使模型不會只依賴 \[MASK\] token，因為這個 token 在微調時從不出現。

論文還預訓練了第二個任務：下一句預測。一半的情況下，第二句確實接在第一句之後；另一半則是語料中的隨機句子。模型根據 \[CLS\] 的狀態判斷是哪一種情況。

預訓練資料為 BooksCorpus（8 億詞）與英文維基百科（25 億詞）。

## 關鍵方法

### BERT：用於語言理解的深度雙向 Transformer 預訓練（Devlin 等人，2019）

- **問題：** 由左至右的語言模型無法利用詞的右側上下文，而且每個任務都需要專屬的架構。
- **核心想法：** 以遮蓋 token 預測與句對預測預訓練一個雙向 Transformer 編碼器，然後為每個任務加上一個輸出層，微調其全部權重。
- **方程式或演算法：** 上述的遮蓋語言模型損失，其中 15% 的 token 被選取，並套用 80/10/10 替換規則。下一句預測的損失是 \[CLS\] 狀態上的二元交叉熵。
- **結果：** 摘要報告 GLUE 分數為 80.5%（絕對提升 7.7 分）、MultiNLI 準確率為 86.7%（提升 4.6 分）、SQuAD v1.1 測試 F1 為 93.2（提升 1.5 分），SQuAD v2.0 測試 F1 為 83.1（提升 5.1 分）。論文宣稱在十一項自然語言處理任務上取得新的最先進結果。
- **限制：** 每個序列中只有 15% 的 token 提供訓練訊號，因此預訓練成本高。\[MASK\] token 在微調時不會出現，80/10/10 規則只能部分處理這個問題。模型是編碼器，因此不像解碼器那樣生成文字。

## 組件與變體

- **模型大小。** BERT-Base 與 BERT-Large 在深度、寬度與注意力頭數上不同。論文中較大的模型表現較好。
- **句子對。** 段落嵌入與 \[SEP\] token 使同一個模型能接收句子對，用於問答與蘊涵等任務。
- **目標。** 下一句預測是論文的兩個預訓練任務之一。之後的變體會改變目標，而 [T5](../t5/index.md) 則使用不同的破壞目標。

## 連結

- BERT 是[架構家族](../index.md)中的編碼器專用成員。其編碼器區塊即[Transformer 與注意力機制](../../index.md)中所述的結構。
- 編碼器–解碼器的替代方案是 [T5](../t5/index.md)，它在文字片段上使用相近的破壞概念。
- 解碼器專用的替代方案見 [GPT-3](../../../llm/gpt-3-few-shot/index.md) 頁面。
- 自然語言處理的應用見 [NLP](../../../nlp/index.md) 頁面。

## 應用

- 文字分類（例如情感與主題標籤），在預訓練編碼器上加一個輸出層。
- SQuAD 類型基準上的問答，模型從段落與問題中預測答案片段。
- 句子對任務，例如自然語言推論與改寫偵測，如 GLUE 基準的結果所示。

## 開放問題

- 下一句預測是否有幫助，或者它只是一個弱訊號，會被其他目標取代。
- 遮蓋 token 的方法有多少能延伸到超大型模型，因為解碼器專用的預訓練已成為預設。
- 如何降低預訓練成本，因為大部分 token 並未作為目標使用。
