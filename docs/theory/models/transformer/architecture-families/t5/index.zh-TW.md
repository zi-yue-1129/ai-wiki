# T5：文字到文字遷移 Transformer

T5（Text-to-Text Transfer Transformer，文字到文字遷移 Transformer）是一種編碼器–解碼器的 [Transformer](../../index.md)，把每個語言任務都視為輸入文字、輸出文字。Raffel 等人（2020）以跨度破壞目標進行預訓練，並以同一種文字格式在每個任務上微調。論文也提出了 C4 語料，並系統性地比較語言遷移學習背後的各種設計選擇。

## 概述

BERT 式的模型需要為每個任務加上專屬的輸出層，而分類、跨度抽取與序列標註所需的輸出層形狀各不相同。T5 消除了這種差異：輸入是一串指出任務的字串，輸出是一串答案字串。翻譯、摘要、分類與問答都使用同一個模型與同一個損失。

論文同時也是一份選擇的比較研究。它在多個語言理解任務上比較預訓練目標、架構、未標註資料集與遷移方法，並報告每個選擇如何影響結果。

## 關鍵概念

- **文字到文字格式**：每個任務都被表述為把輸入字串映射成輸出字串。分類的輸出是標籤詞，而非類別索引。
- **跨度破壞（span corruption）**：輸入中隨機的跨度被替換為哨兵 token，目標則是被移除的跨度序列，每段前面接著其哨兵。
- **C4（Colossal Clean Crawled Corpus）**：約 750 GB、經過清理的網路文字語料，用於預訓練。
- **模型大小**：論文訓練的模型最大達 110 億參數。

## 運作方式

編碼器以雙向自注意力讀取被破壞的輸入。解碼器則以因果自注意力與對編碼器輸出的交叉注意力，逐 token 生成目標序列。損失是目標 token 上常見的交叉熵。

在跨度破壞中，論文隨機移除 15% 的輸入 token，並把每段連續被移除的 token 替換為一個哨兵 token。目標是被移除的跨度序列，每段前面接著其哨兵。這與 BERT 式的遮蓋語言模型不同：目標是被移除的跨度，而非原位的遮蓋 token，且跨度由解碼器生成。

\[
\mathcal{L} = -\sum_{t} \log p_\theta\big(y_t \mid y_{<t},\ \tilde{x}\big)
\]

其中 \(\tilde{x}\) 是帶有哨兵的被破壞輸入，\(y\) 是被移除跨度的目標序列。

## 關鍵方法

### Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer（Raffel 等人，2020）

- **問題：** 語言的遷移學習有許多方法，各自有不同的任務格式與架構，因此很難判斷哪些設計選擇真正重要。
- **核心想法：** 把每個任務都放進同一種文字到文字的格式，在大型乾淨語料上以去噪目標預訓練編碼器–解碼器，並在同一個框架下系統性地比較各種設計選擇。
- **方程式或演算法：** 上述的跨度破壞交叉熵，其中 15% 的輸入 token 被移除，並以哨兵標記的跨度取代。
- **結果：** 摘要報告，結合這項探索、規模化與 C4 語料後，在許多基準上取得最先進的結果，涵蓋摘要、問答與文字分類。論文釋出資料集、預訓練模型與程式碼。最大的模型有 110 億參數。
- **限制：** 110 億參數的模型訓練與服務成本高，且論文的比較是在固定的計算預算下進行。文字到文字的格式也需要為每個任務產生一個輸出字串，對於具有豐富結構輸出的任務可能不便。

## 組件與變體

- **架構。** 論文在同一個框架下比較編碼器–解碼器與解碼器專用的變體，並報告它們在其任務套件上的差異。
- **目標。** 論文中，跨度破壞與 BERT 式遮蓋以及前綴語言模型（prefix language modelling）進行了比較。
- **規模。** 釋出的模型有多種尺寸，其中 110 億參數的最大模型是報告最高結果的那一個。

## 連結

- T5 是[架構家族](../index.md)中的編碼器–解碼器成員。其編碼器與解碼器區塊即[Transformer 與注意力機制](../../index.md)中所述的結構。
- [BERT](../bert/index.md) 是編碼器專用的替代方案，其遮蓋目標正是跨度破壞所推廣的對象。
- 解碼器專用的替代方案見 [GPT-3](../../../llm/gpt-3-few-shot/index.md) 頁面。
- 語言應用見 [NLP](../../../nlp/index.md) 頁面。

## 應用

- 摘要與翻譯，每個任務使用一個微調後的模型。
- 問答與文字分類，表述為生成答案字串。
- 遷移到新的語言任務，只需撰寫任務前綴與目標字串，不需要新的輸出層。

## 開放問題

- 在超大規模的指令資料訓練下，文字到文字格式是否仍有幫助，因為那時解碼器專用模型佔主導地位。
- 比較研究的結論在多大程度上依賴其所用的固定計算預算。
- 跨度破壞是否為最佳的去噪目標，或其他破壞模式能否帶來更好的遷移。
