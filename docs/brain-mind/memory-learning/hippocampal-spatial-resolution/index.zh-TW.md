# 海馬迴的空間解析度

海馬迴以多種尺度表徵空間，而一個位置細胞的位置場大小，取決於它位於何處、動物經歷過什麼，以及它正在執行的任務。問題在於，哪些因素會分配解析度，以及這些變異有多少是結構本身，多少只是取樣造成的。目前沒有定論。部分結果指向固定的解剖梯度，另一些指向學習與獎勵，還有少數顯示，表面上的分配可能只是計數方式造成的。

本頁是[記憶與學習的神經機制](../index.zh-TW.md)的子主題。它整理這一主題的證據，並連結到更廣的記憶與導航研究。

## 概述

位置細胞在動物位於環境中某個特定區域時放電，而該區域的大小就是它的位置場。向海馬迴提供輸入的內嗅皮質格細胞，則以間距也會變化的場來鋪滿空間。一個反覆出現的想法是：大腦會把解析度集中在重要之處，因此目標附近或動物學習過的區域，場會比較密。本頁檢視這個想法有多少證據支持，以及哪些地方並不支持。

## 問題

有三個問題組織了這個領域：

- 空間表徵的尺度是由解剖決定，還是會隨經驗改變？
- 目標與獎勵是否會吸引更多位置場集中到自己附近？
- 密度上的差異是真的，還是來自環境取樣不均？

## 研究發現

### 固定的多尺度骨架

在大鼠身上，位置場的尺度沿海馬迴的長軸增加：背側不到 1 公尺，腹側約 10 公尺（Kjelstrup 等人，2008）。內嗅皮質中的格狀間距也沿相同的背側到腹側方向增加（Brun 等人，2008），而格細胞分屬少數幾個離散的模組，相鄰模組的間距比接近 1.4（Stensola 等人，2012）。在一條 200 公尺長隧道中飛行的蝙蝠，單一細胞可以攜帶相差達二十倍的場，因此多解析度編碼可能存在於單一神經元之內（Eliav 等人，2021）。

部分結構仍有爭議。蝙蝠的格細胞沒有持續的θ節律，這與以振盪干涉解釋格狀尺度的模型難以調和（Yartsev 等人，2011）。格狀對稱性也取決於圍欄的形狀（Krupic 等人，2015），因此這套骨架並非完全獨立於環境。

### 經驗與新穎性會改變場的大小

反覆穿越會放大位置場，而且這種擴張是不對稱的，會向行進方向的反方向延伸（Mehta 等人，1997）。格狀尺度在新環境中會擴張，並在數十分鐘內收縮回去（Barry 等人，2012），而且會隨熟悉環境的大小與形狀重新調整（Barry 等人，2007）。經過七天，穩定帶有場的細胞數量與它們的穩定性都會增加（Vaidya 等人，2025）。一種基於樹突平台電位的一次性機制，可以在單次經過時建立一個場（Bittner 等人，2017）。

這些發現常被解讀為追蹤新穎性與熟悉度，而非重要性。格狀擴張在初次接觸時就會發生，這是新穎性的訊號，與目標的價值是不同的訊號。

### 目標與獎勵使空間過度表徵

在水迷宮中，位置場會在隱藏平台附近累積（Hollup 等人，2001）。內嗅地圖會向已學會的目標偏移（Boccara 等人，2019）；記住的獎勵位置會重組內嗅地圖，使獎勵附近的位置解碼更準確（Butler 等人，2019）。CA1 中獎勵區的過度表徵依賴內嗅皮質的輸入，抑制內嗅皮質第 3 層時，這種過度表徵大部分會消失（Grienberger 與 Magee，2022）。朝向新目標的重組出現在 CA1，而非 CA3（Dupret 等人，2010）。

目標編碼也有向量形式。蝙蝠海馬迴中的細胞會調諧於目標的方向與距離（Sarel 等人，2017）；位置細胞的向量場會收斂到目標上（Ormond 與 O'Keefe，2022）。後者發現，覓食時只有一小部分位置細胞具有朝向目標的場，這表示目標訊號取決於任務。

### 相反的證據

當獎勵的給予與目標位置脫鉤時，場中心不會在目標附近累積，目標區的放電率也與對照區相當（Duvelle 等人，2019）。這是對簡單獎勵解釋最強的反例，同時也排除了某種特定的取樣假象，因為動物在兩種條件下的行為相同。

地形形狀是另一個不依賴動物去過哪裡的驅動因素。場會沿地形等高線延伸，而邊界向量細胞模型可以重現這一點（Grieves 等人，2026）。這表示場的位置可以跟隨環境中的結構，而不只是動物的行為。

### 測量

估計場的密度本身就是偏差的來源。樣本數有限時，粗略的空間資訊估計會被高估，而取樣最少的地方偏差最大（Sheintuch 等人，2022）。一項報告偏好位置上場累積的研究，其作者也承認，過度取樣可能解釋部分效應（Mamad 等人，2017）。因此，比較不同區域或條件下的密度時，需要佔用量匹配或代理資料正規化的對照。

## 證據摘要

| 主張 | 主要支持 | 主要限制 |
|---|---|---|
| 沿長軸的尺度梯度 | 大鼠線性軌道與格細胞的記錄 | 蝙蝠隧道中的記錄顯示不同的尺度範圍 |
| 經驗會放大場 | 反覆穿越與新穎性研究 | 擴張在初次接觸時就已出現，可能反映新穎性而非使用 |
| 目標會吸引場 | 水迷宮、與獎勵鎖定的記錄、因果性抑制 | 獎勵給予與目標脫鉤時，累積現象不再出現 |
| 地形會塑造場 | 近期在不平地形上的場記錄 | 目前主要依賴一項研究 |

## 開放問題

- 分配究竟是單一細胞的性質、族群的性質，還是兩者皆是。Eliav 等人（2021）顯示單一細胞內有多個尺度，但族群如何結合這些尺度尚無定論。
- 目標效應有多少來自獎勵、注意力或規劃。Duvelle 等人（2019）指出，單靠獎勵的給予並不會驅動累積，因此目標位置與任務需求的角色仍待釐清。
- 在實務上，如何把真正的分配與取樣假象分開。測量研究提供了工具，但許多論文仍使用未經校正的計數。
