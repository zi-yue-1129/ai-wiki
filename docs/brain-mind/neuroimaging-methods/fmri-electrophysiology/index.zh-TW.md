# 功能性磁振造影與電生理同步記錄（Logothetis 等人，2001）

Logothetis 等人（2001）在猴子的皮質中記錄電活動，同時對同一隻動物進行功能性磁振造影，使 BOLD 訊號與神經訊號可以直接比較。論文探問 BOLD 反應追蹤的是哪一種神經測量：是脈衝輸出，還是驅動它的突觸輸入。本頁所用摘要中的核心發現是，BOLD 訊號與局部場電位的關係比與個別神經元脈衝的關係更密切；局部場電位主要反映突觸活動。

本頁是[神經影像與記錄方法](../index.md)的子頁。上層頁面提供概述，本頁說明方法與證據。

## 問題

功能性磁振造影被廣泛使用，但它的詮釋取決於它反映哪一種神經訊號。如果 BOLD 反應追蹤脈衝，功能性磁振造影圖就會顯示神經元輸出改變的位置。如果它追蹤突觸輸入，圖就會顯示傳入訊號與局部處理改變的位置，這是另一個量。問題在於它究竟是哪一個。

## 方法

作者在同一批猴子身上，於視覺刺激期間同時進行功能性磁振造影與電極記錄。他們在記錄 BOLD 反應的同時，也記錄每個電極附近的局部場電位與神經元脈衝，然後比較每種神經測量對 BOLD 訊號的預測能力。

步驟如下：

1. 在麻醉的猴子身上，於進行功能性磁振造影的同時呈現視覺刺激。
2. 在同一位點記錄局部場電位與單一神經元的脈衝。
3. 把 BOLD 反應與各種神經測量相關聯，比較哪一種預測得更好。
4. 在不同刺激強度下檢驗這種關係，以確認它不只限於單一條件。

第 3 步是關鍵的比較。答案取決於局部場電位與脈衝可能分歧這一事實，因此兩種測量會給出不同的預測。

## 結果

摘要指出，BOLD 訊號比脈衝更緊密地追蹤局部場電位，這顯示功能性磁振造影反應反映的是位點周圍的輸入與局部處理。在本頁所用的摘要中，這些結果是定性的。引用具體數值前，請查閱全文。

## 限制

- 記錄來自麻醉的猴子，因此推廣到清醒的人類需要另外的證據。
- 局部場電位與脈衝是在每個電極附近測量的，只取樣了功能性磁振造影所涵蓋區域的一小部分。
- 這種關係在不同腦區、任務與活動水準下可能不同。

## 與其他主題的關聯

- **BOLD 方法**：血氧測量的基礎見 [BOLD 功能性磁振造影](../bold-fmri/index.md)，該方法依賴本文所檢驗的耦合。
- **視覺皮質**：脈衝測量背後的單神經元記錄傳統，摘要於[知覺與視覺系統](../../visual-perception/index.md)。
- **語言**：同樣的 fMRI 反映什麼的問題也出現在句子研究中，ECoG 提供了較快的比較，見[大腦中的語言](../../language-in-brain/index.md)。
- **神經科學背景**：脈衝與突觸活動的差異，見[神經科學基礎](../../neuroscience/index.md)。

## 開放問題

- **這種耦合在人類與清醒的動物身上是否成立？** 結果來自麻醉的猴子，而耦合可能隨狀態改變。
- **耦合在不同區域之間如何變化？** 不同區域的突觸輸入與輸出比例可能不同，這會改變應如何解讀功能性磁振造影圖。
