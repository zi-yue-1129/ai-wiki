# 活動靜默工作記憶（Mongillo 等人，2008；Stokes，2015）

活動靜默工作記憶是一種觀點：資訊可以在延遲期間被保存，而神經元不必持續放電。記憶由短暫的突觸強度變化或其他隱藏狀態承載，需要時，短暫的再活化可以讓它重新回到放電狀態。Mongillo、Barak 與 Tsodyks（2008）提出一個明確的突觸模型；Stokes（2015）則回顧證據，並提出動態編碼框架。

本頁是[工作記憶與執行功能](../index.md)之下的一種方法。競爭的觀點認為記憶靠持續放電來維持，該概述頁已總結這一觀點。

## 概述

長久以來，工作記憶被認為是持續性的：神經元在延遲期間持續放電，而這種放電就是記憶本身。近期的研究顯示，延遲期間的活動往往隨當前所保持項目的任務相關性而起伏，而且即使記憶仍被保持，群體層級的活動也持續在變化。Stokes（2015）提出的問題是：當底層活動一直在移動時，穩定的記憶如何存在？

活動靜默的觀點回答：記憶中穩定的部分未必存在於放電之中。它可以儲存在突觸或其他隱藏狀態中，因此在延遲期間放電可以停止。

## 問題

若記憶只依賴持續放電，維持記憶將代價高昂且脆弱，而且放電模式必須在整個延遲期間保持穩定。有兩項觀察挑戰了這個看法：持續的延遲活動並不總是伴隨維持，而群體活動具有高度動態性。問題在於，當可見的活動無法維持穩定時，資訊如何在延遲期間存活。

## 核心理念

這個觀點包含兩個相互連結的想法。

1. **突觸儲存。** Mongillo 等人（2008）提出，工作記憶是由新皮質網路遞迴連結中、鈣介導的突觸易化所維持。突觸前的殘餘鈣作為緩衝。放電會裝載、刷新並讀出這個緩衝。由於鈣的衰減很慢，刷新可以不頻繁，因此此機制兼具代謝效率與穩健性。
2. **動態隱藏狀態。** Stokes（2015）主張，記憶可以由隨任務相關性改變的暫態活動狀態承載，並說明穩定的記憶如何與變動的活動並存。Wolff 等人（2017）以延遲期間的擾動脈衝支持這一點，使項目特定的記憶得以在 EEG 中被偵測到。

## 方程式或演算法

沒有單一方程式能概括此框架。以下以編號步驟描述突觸版本的機制。

1. 某個群體的短暫放電會把殘餘鈣裝載進其遞迴突觸，使該群體內部的連結增強。
2. 在兩次刷新之間，鈣緩慢衰減，因此突觸易化以及它所編碼的記憶得以在沒有持續放電的情況下延續。
3. 刷新（可以是短暫的放電爆發，或一個刺激）會讀出記憶並重新裝載鈣。
4. 自發的背景活動決定記憶能持續多久、有多穩定。

這些步驟描述的是簡化模型。其他突觸機制也有可能，而 Stokes（2015）對隱藏狀態的討論比任何單一機制都更廣。

## 結果

- **突觸模型。** Mongillo 等人（2008）顯示，突觸記憶可以在低刷新率下維持，且其持續時間可由背景活動控制。作者將此機制描述為穩健且代謝有效率。
- **脈衝式證據。** Wolff 等人（2017）在保持期間使用 EEG 與擾動脈衝。針對某項目的遺忘提示會抹除該項目的痕跡，而僅僅未被注意的項目則仍被編碼。這種隱藏狀態編碼的強度可預測記憶引導反應的正確率與精確度。

## 限制

- **證據間接。** 隱藏狀態是由解碼與擾動推斷出來的，並非直接觀察。脈衝可以揭示記憶，但它本身也會改變被測量的狀態。
- **持續放電仍然存在。** 許多前額葉研究都報告了持續的延遲活動（Curtis 與 D'Esposito，2003）。活動靜默的觀點可能較能描述某些條件，而邊界尚未確定。
- **模型的特定性。** 突觸模型只是一種特定機制，而該框架是動態的論述，而非單一實驗。

## 連結

- **持續活動。** 持續放電的觀點由 Compte 等人（2000）的網路模型與 Funahashi 等人（1989）的記錄所代表，兩者已在[上層概述](../index.md)中總結。
- **突觸可塑性。** Mongillo 等人（2008）中以鈣為基礎的儲存，依賴於[長期增益](../../memory-learning/long-term-potentiation/index.md)所研究的同類突觸變化。此連結屬概念層面，兩者的時間尺度並不相同。
- **閘控式維持。** [PBWM](../pbwm/index.md)將維持描述為主動、受閘控的儲存區。兩種觀點可能分別適用於任務的不同部分。
- **神經影像。** 讀取隱藏狀態需要不依賴放電的方法，例如以 EEG 進行擾動。見[神經影像與記錄方法](../../neuroimaging-methods/index.md)。
- **AI。** 突觸式的記憶觀點，是將其類比為儲存在會改變的權重之中，而非對機器記憶如何實作的說明。[Transformer](../../../theory/models/transformer/index.md)頁描述了一種機器設計。

## 應用

- **實驗設計。** 擾動與解碼方法，例如 Wolff 等人（2017）的脈衝設計，被用來在持續活動無法顯示記憶時讀出記憶。
- **維持的模型。** 工作記憶的突觸模型，啟發了以連結強度而非持續放電來保存記憶的網路模型（Mongillo 等人，2008）。

## 未解問題

- **在某個任務中，是哪一種機制保存記憶？** 突觸儲存、動態隱藏狀態與持續放電都有支持證據。有利於各者的條件尚不清楚。
- **隱藏狀態如何被再活化？** 刷新可以由刺激、注意力或自發活動觸發。這些觸發因素各自的角色仍未解決。
- **儲存與容量有何關係？** 活動靜默儲存能否解釋 Cowan（2001）與 Ma 等人（2014）所報告的容量限制，是開放問題。

## 參考文獻

### 開創性論文

- Mongillo, G., Barak, O. & Tsodyks, M. (2008). Synaptic theory of working memory. *Science*. https://doi.org/10.1126/science.1150769 — 提出工作記憶由鈣介導的突觸易化維持，並由放電刷新。
- Wolff, M. J., Jochim, J., Akyürek, E. G. & Stokes, M. G. (2017). Dynamic hidden states underlying working-memory-guided behavior. *Nature Neuroscience*. https://doi.org/10.1038/nn.4546 — 以 EEG 與擾動脈衝偵測延遲期間的項目特定記憶；此訊號的強度可預測記憶引導的行為。
- Compte, A. et al. (2000). Synaptic mechanisms and network dynamics underlying spatial working memory in a cortical network model. *Cerebral Cortex*. https://doi.org/10.1093/cercor/10.9.910 — 活動靜默觀點所比較的持續活動網路模型。

### 綜述與回顧

- Stokes, M. G. (2015). 'Activity-silent' working memory in prefrontal cortex: a dynamic coding framework. *Trends in Cognitive Sciences*. https://doi.org/10.1016/j.tics.2015.05.004 — 回顧延遲活動並不總是伴隨維持的證據，並提出動態編碼框架。
- Curtis, C. E. & D'Esposito, M. (2003). Persistent activity in the prefrontal cortex during working memory. *Trends in Cognitive Sciences*. https://doi.org/10.1016/S1364-6613(03)00197-9 — 回顧工作記憶期間前額葉持續延遲活動的證據，這是活動靜默觀點所修正的看法。
