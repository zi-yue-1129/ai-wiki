# 神經科學基礎

## 規模感

| 項目 | 數量（約略） |
|---|---|
| 人腦神經元 | 約 860 億 |
| 大腦皮質神經元 | 約 160 億 |
| 小腦神經元 | 約 690 億 |
| 突觸 | 約 10¹⁴–10¹⁵ |
| 膠質細胞 | 與神經元數量相近 |

## 神經元

```mermaid
flowchart LR
  D[樹突<br/>接收訊號] --> S[細胞體<br/>整合]
  S --> AH[軸丘<br/>決定是否放電]
  AH --> AX[軸突<br/>傳導動作電位]
  AX --> T[軸突末梢<br/>釋放神經傳導物質]
  T -.突觸.-> D2[下一個神經元的樹突]
```

- **靜止膜電位**約 −70 mV
- **動作電位**：膜電位超過閾值（約 −55 mV）時，鈉離子湧入、鉀離子流出，產生約 1 毫秒、「全有或全無」的電脈衝
- **編碼**：資訊可由放電頻率（rate code）、精確時序（temporal code）、群體活動（population code）攜帶
- **神經元種類**：興奮性（錐狀細胞，皮質約 80%）、抑制性中間神經元（PV、SST、VIP 等多種亞型）

## 突觸與神經傳導物質

| 物質 | 主要作用 |
|---|---|
| 麩胺酸（Glutamate） | 主要興奮性傳導物質，學習記憶（NMDA、AMPA 受體） |
| GABA | 主要抑制性傳導物質 |
| 多巴胺 | 獎勵預測誤差、動機、運動（帕金森氏症） |
| 血清素 | 情緒、耐心、睡眠 |
| 正腎上腺素 | 警覺、注意、探索／利用 |
| 乙醯膽鹼 | 注意、學習、肌肉控制 |

**神經調節物質**（多巴胺、血清素、正腎上腺素、乙醯膽鹼）不直接傳遞訊息，而是調整整個網路的學習率與運作模式。Doya（2002）提出它們分別對應 RL 中的 TD 誤差、折扣因子、探索溫度、學習率——是神經調節的計算理論代表。

## 主要腦區與功能

| 腦區 | 功能 | AI 對照 |
|---|---|---|
| 枕葉視覺皮質（V1–V4、IT） | 視覺處理階層 | CNN、ViT |
| 顳葉 | 聽覺、語言理解、物體辨識、記憶 | 語音模型、語言模型 |
| 頂葉 | 空間、注意、感覺整合 | 多模態整合 |
| 額葉／前額葉 | 規劃、工作記憶、決策、執行控制 | 規劃模組、代理人控制器 |
| 運動皮質 | 動作規劃與執行 | 機器人控制 |
| 海馬迴 | 情節記憶、空間導航、重播 | 經驗回放、記憶增強網路、RAG |
| 基底核（紋狀體等） | 行動選擇、習慣、強化學習 | Actor-Critic |
| 小腦 | 運動協調、預測、時序 | 監督式學習、前向模型 |
| 視丘 | 感覺中繼、注意閘控 | 路由、閘控機制 |
| 杏仁核 | 情緒、恐懼學習 | 價值評估 |
| 語言區（布洛卡區、韋尼克區與更廣的左側語言網路） | 語言產出與理解 | LLM |

### 大腦皮質的結構

- 六層結構，具有重複的**皮質柱**（Mountcastle）——有人假設皮質使用一種通用演算法（Hawkins 的千腦理論即基於此）
- 大量的**回饋連結**：從高階往低階的連結數量甚至多於前饋，這是目前前饋式深度網路缺乏的特徵
- **稀疏活動**：任一時刻只有少數神經元活躍，有利於能源效率

## 研究方法

| 方法 | 空間解析度 | 時間解析度 | 侵入性 |
|---|---|---|---|
| fMRI | 毫米 | 秒 | 非侵入 |
| EEG | 公分 | 毫秒 | 非侵入 |
| MEG | 公分以下 | 毫秒 | 非侵入 |
| fNIRS | 公分 | 秒 | 非侵入 |
| ECoG | 毫米 | 毫秒 | 需開顱 |
| 單一神經元記錄／Neuropixels 探針 | 單一細胞 | 次毫秒 | 侵入 |
| 鈣離子成像 | 單一細胞 | 數十毫秒 | 侵入（動物） |
| 光遺傳學 | 特定細胞類型 | 毫秒 | 侵入（動物）——可以「操控」而非只觀察 |
| 電子顯微鏡連結體學 | 奈米 | — | 死後組織 |

**AI 已成為神經科學的核心工具**：自動分割電子顯微鏡影像重建連結體、DeepLabCut 追蹤動物姿態、Kilosort 分類神經元脈衝、從 fMRI 解碼影像、大型神經資料的基礎模型（如以多隻小鼠視覺皮質資料訓練的神經活動預測模型）。

## 大腦 vs 電腦

| 面向 | 大腦 | 數位電腦／GPU |
|---|---|---|
| 運算單元速度 | 慢（毫秒） | 快（奈秒） |
| 平行度 | 極高 | 高 |
| 記憶與運算 | 同處（突觸） | 分離（馮紐曼瓶頸） |
| 訊號 | 類比＋脈衝、有雜訊 | 數位、精確 |
| 能耗 | 約 20 W | 訓練前沿模型需數十 MW 等級的資料中心 |
| 學習 | 持續、局部、少樣本 | 多為離線批次、全域反向傳播 |
| 容錯 | 高 | 低 |
